РОЗДІЛ 01

Події та простір елементарних подій

⬡ Експеримент і подія

Експеримент (дослід, спроба) — послідовність операцій, виконуваних з додержанням певного комплексу умов. Подія — наслідок експерименту. Експеримент необов'язково виконує людина: його може проводити прилад чи комп'ютер, а людина лише фіксує наслідок.

Теорія ймовірностей вивчає закономірності масових випадкових подій — таких, наслідки яких неоднозначні через дію численних дрібних факторів, які експериментатор не в змозі врахувати.

⬡ Прості та складені події

Проста (елементарна) подія ωi — подія, що може відбутися внаслідок проведення однієї і лише однієї спроби. Не поділяється на простіші складові (як точка в геометрії).

Складена подія A — її можна розкласти на елементарні події. Записується як підмножина простору: A ⊂ Ω. Елементарні події ωi ∈ A називають такими, що сприяють появі події A.

Приклад: монету підкидають тричі — простір елементарних подій містить 8 елементів (кожне підкидання дає 2 наслідки, 2³ = 8): ω₁ = ггг ω₂ = ццц ω₃ = ггц ω₄ = гцг ω₅ = цгг ω₆ = гцц ω₇ = цгц ω₈ = ццг Складена подія A = "герб випав двічі" = {ω₃, ω₄, ω₅} ↑ ↑ ↑ ггц гцг цгг Елементарні події ω₃, ω₄, ω₅ сприяють появі A.
⬡ Простір елементарних подій

Простір елементарних подій Ω — множина всіх ωi, що можуть відбутися в експерименті. Це математична модель ідеалізованого експерименту: будь-який його наслідок описується однією і лише однією елементарною подією.

Елементарні події задовольняють три твердження:

  • Несумісність попарно: ωi ∩ ωj = ∅ при i ≠ j
  • Утворюють повну групу: ⋃ ωi = Ω
  • Рівноможливі (для класичної моделі)
⬡ Дискретний vs неперервний простір
Тип Ω Властивість Приклад
Дискретний Множина зчисленна — елементи можна перелічити або пронумерувати натуральними числами Підкидання кубика: Ω = {1,2,3,4,5,6}
Неперервний Множина незчисленна — між будь-якими двома елементами є нескінченно багато інших Розмір деталі (діаметр), покази вольтметра

Дискретний простір може бути обмеженим (n елементів) чи необмеженим (нескінченна послідовність).

⬡ Канонічний приклад: пари чисел з двох множин

Дано Ω₁ = {1, 2, 3} і Ω₂ = {1, 2, 3, 4}. Із кожної множини беруть навмання по одному числу. Простір елементарних подій містить 3·4 = 12 пар:

ω₁ = (1,1) ω₅ = (2,1) ω₉ = (3,1) ω₂ = (1,2) ω₆ = (2,2) ω₁₀ = (3,2) ω₃ = (1,3) ω₇ = (2,3) ω₁₁ = (3,3) ω₄ = (1,4) ω₈ = (2,4) ω₁₂ = (3,4) |Ω| = 12 елементарних подій
Природа елементарних подій у теорії ймовірностей неістотна — як точка в геометрії. Важливі лише їх кількість і структурні відношення (несумісність, повнота групи, рівноможливість).
РОЗДІЛ 02

Операції над подіями та аксіоми

⬡ Три базові операції
Операція Запис Зміст
Сума (об'єднання) A ∪ B Настає принаймні одна з подій A або B
Добуток (переріз) A ∩ B Одночасно настають обидві події A і B
Різниця A \ B Настає A і одночасно не настає B
⬡ Канонічний приклад: операції на множині чисел

Ω = {1, 2, …, 15}. A — число, кратне 2. B — число, кратне 3.

A = {2, 4, 6, 8, 10, 12, 14} B = {3, 6, 9, 12, 15} A ∪ B = {2, 3, 4, 6, 8, 9, 10, 12, 14, 15} ← хоча б одна з умов A ∩ B = {6, 12} ← обидві умови (кратне 6) A \ B = {2, 4, 8, 10, 14} ← кратне 2, але не 3
⬡ Сумісні vs несумісні. Повна група. Протилежні
  • Сумісні: A ∩ B ≠ ∅
  • Несумісні: A ∩ B = ∅
  • Повна група: A₁ ∪ A₂ ∪ … ∪ An = Ω. Якась з подій Ai обов'язково настане.
  • Протилежні A та A̅: дві несумісні події, що утворюють повну групу. Виконується A ∪ A̅ = Ω, A ∩ A̅ = ∅.
⬡ Закони алгебри подій

Для подій A, B, C ⊂ Ω виконуються:

Назва Тотожність
Ідемпотентність A ∪ A = A; A ∩ A = A
Комутативність ∪ A ∪ B = B ∪ A
Комутативність ∩ A ∩ B = B ∩ A
Асоціативність ∪ (A ∪ B) ∪ C = A ∪ (B ∪ C)
Асоціативність ∩ (A ∩ B) ∩ C = A ∩ (B ∩ C)
Дистрибутивність 1 (A ∪ B) ∩ C = (A ∩ C) ∪ (B ∩ C)
Дистрибутивність 2 (A ∩ B) ∪ C = (A ∪ C) ∩ (B ∪ C)
З Ω і ∅ A ∪ Ω = Ω; A ∩ Ω = A; A ∪ ∅ = A; A ∩ ∅ = ∅
Доповнення A̅ = Ω \ A; ∅̅ = Ω; Ω̅ = ∅
Закон де Моргана 1 A ∪ B = A̅ ∩ B̅
Закон де Моргана 2 A ∩ B = A̅ ∪ B̅
⬡ Алгебра подій

Алгебра подій Θ — система випадкових подій, замкнена відносно операцій ∪, ∩, \. Формально:

  • Ω ∈ Θ
  • Якщо A ∈ Θ і B ∈ Θ, то A ∪ B ∈ Θ, A ∩ B ∈ Θ, A \ B ∈ Θ

Звідси випливає, що ∅ = Ω \ Ω ∈ Θ. Для скінченного Ω з n елементів кількість підмножин (потужність алгебри) становить 2n.

⬡ Аксіоми Колмогорова

Числова функція P, визначена на алгебрі подій Θ, називається ймовірністю, якщо:

  1. Θ є алгеброю подій
  2. Для будь-якого A ∈ Θ існує P(A) ≥ 0
  3. P(Ω) = 1
  4. Аксіома адитивності: якщо A ∩ B = ∅, то P(A ∪ B) = P(A) + P(B)
  5. Аксіома неперервності (для нескінченних послідовностей): для будь-якої спадної послідовності A₁ ⊃ A₂ ⊃ … з ⋂ Ai = ∅ виконується lim P(An) = 0

Трійка (Θ, Ω, P), де Θ — алгебра подій і P задовольняє аксіоми, називається простором ймовірностей.

⬡ Наслідки аксіом

Якщо A₁, A₂, …, An попарно несумісні:

P ( ⋃ i = 1 n A i ) = ∑ i = 1 n P ( A i )
(7) адитивність для попарно несумісних

Якщо A₁, …, An утворюють повну групу:

P ( ⋃ i = 1 n A i ) = 1
(8) повна група

Імовірність протилежної події:

P ( A ― ) = 1 − P ( A )
(9) ймовірність доповнення

Сума двох сумісних подій (формула включень/виключень):

P ( A ∪ B ) = P ( A ) + P ( B ) − P ( A ∩ B )
(10) формула для двох сумісних подій

Для трьох сумісних подій:

P ( A ∪ B ∪ C ) = P ( A ) + P ( B ) + P ( C ) − P ( A ∩ B ) − P ( A ∩ C ) − P ( B ∩ C ) + P ( A ∩ B ∩ C )
(13) формула для трьох сумісних подій

Монотонність: якщо A ⊂ B, то P(A) ≤ P(B).

★ Пам'ятайте різницю: для несумісних A ∪ B працює проста сума P(A) + P(B). Для сумісних — обов'язково віднімаємо перетин: P(A) + P(B) − P(A ∩ B). Найчастіша помилка на іспиті — забути цей член.
РОЗДІЛ 03

Означення ймовірності

⬡ Класичне означення

Імовірністю випадкової події A називається невід'ємне число P(A), що дорівнює відношенню кількості елементарних подій m, які сприяють появі A, до кількості всіх n рівноможливих елементарних подій простору Ω:

P ( A ) = m n
(1) класичне означення ймовірності
де: m — число елементарних подій, які сприяють A; n — загальне число рівноможливих елементарних подій.

Властивості: для неможливої події P(∅) = 0 (m = 0); для вірогідної P(Ω) = 1 (m = n); для довільної 0 ≤ P(A) ≤ 1.

Працює лише за обмеженого числа рівноможливих елементарних подій.

⬡ Канонічний приклад: бракована/стандартна деталь

У ящику 15 однотипних деталей: 6 бракованих, 9 стандартних. Навмання беруть одну. Ймовірність вибрати стандартну?

n = 15 , m = 9 ⇒ P ( A ) = 9 15 = 3 5 = 0.6
розв'язання
⬡ Приклад на сполучення

У ящику 13 деталей: 8 стандартних, 5 бракованих. Навмання беруть 4. Знайти P(A ∪ B), де A — всі 4 стандартні, B — всі 4 браковані.

n = C 13 4 = 13 ! 4 ! · 9 ! = 715 m 1 = C 8 4 = 70 , m 2 = C 5 4 = 5 P ( A ∪ B ) = 70 715 + 5 715 = 15 143 ≈ 0.105
несумісні події A ∩ B = ∅, тому додавання просте
⬡ Геометрична ймовірність

Коли простір Ω неперервний (нескінченне число рівноможливих наслідків), класичне означення не працює. Замість підрахунку сприятливих елементів — порівняння мір множин:

P ( A ) = m ( A ) m ( Ω )
(15) геометрична ймовірність
де: m — лінійна довжина, площа або об'єм залежно від розмірності Ω.
⬡ Канонічний приклад: пошкодження трубопроводу

По трубопроводу довжиною 2 км перекачують нафту. Знайти ймовірність того, що пошкодження станеться на ділянці 100 м.

Ω = { 0 ≤ ℓ ≤ 2 км } , A = { 0 ≤ ℓ ≤ 0.1 км } P ( A ) = m ( A ) m ( Ω ) = 0.1 2 = 1 20 = 0.05
розв'язання — відношення довжин

Ω = {0 ≤ x ≤ e, 0 ≤ y ≤ 1}. Знайти ймовірність, що навмання обрана точка потрапить в A = {1 ≤ x ≤ e, 0 ≤ y ≤ ln x}.

S ( Ω ) = e · 1 = e S ( A ) = ∫ 1 e ln x d x = [ x ln x − x ] 1 e = e − e + 1 = 1 P ( A ) = S ( A ) S ( Ω ) = 1 e

⬡ Статистична ймовірність

Для більшості реальних задач (особливо економічних) обчислити P(A) теоретично неможливо. У цьому разі використовують статистичну ймовірність, яка базується на спостереженнях.

Відносна частота події A після n експериментів:

W ( A ) = m n
(16) відносна частота
де: m — кількість експериментів, у яких подія A спостерігалась; n — загальна кількість проведених експериментів. Завжди виконується 0 ≤ W(A) ≤ 1.

За статистичну ймовірність береться значення Wi на кроці серії експериментів, де виконується |Wi − Wi−1| < ε для малого ε > 0. Передумова — стабільність відносних частот: при зростанні n значення Wi(A) групуються навколо деякої константи P(A).

Означення Коли працює Як обчислюємо
Класичне Скінченне Ω, рівноможливі ωi P(A) = m / n
Геометричне Неперервне Ω, квадровна множина P(A) = m(A) / m(Ω)
Статистичне Складні задачі, де теоретичне Ω недоступне P(A) ≈ W(A) = m / n при великому n
РОЗДІЛ 04

Умовна ймовірність. Залежні та незалежні події

⬡ Залежні vs незалежні події

Події A та B називають залежними, якщо поява однієї впливає на ймовірність появи іншої. Інакше — незалежними.

Сценарій Залежність Чому
Дві кульки з урни без повернення Залежні Перший вибір змінює склад урни — змінюється ймовірність другого
Дві кульки з урни з поверненням Незалежні Склад урни той самий перед кожним вийманням
Підкидання кубика і монети Незалежні Експерименти фізично роз'єднані
⬡ Умовна ймовірність

Умовна ймовірність P(A/B) — імовірність події A за умови, що B вже відбулася:

P ( A / B ) = P ( A ∩ B ) P ( B ) , P ( B ) ≠ 0
(17) умовна ймовірність A відносно B
P ( B / A ) = P ( A ∩ B ) P ( A ) , P ( A ) ≠ 0
(18) умовна ймовірність B відносно A

Властивості: P(A/B) = 0, якщо A ∩ B = ∅; P(A/B) = 1, якщо A ∩ B = B (тобто B ⊂ A); 0 < P(A/B) < 1 в інших випадках. Якщо P(A) = P(A/B), то A та B незалежні. Інакше — залежні.

⬡ Канонічний приклад: число кратне 3 за умови непарності

Ω = {1, 2, …, 12}. Навмання беруть число. Знайти P(A/B), де A — кратне 3, B — непарне.

A = { 3 , 6 , 9 , 12 } , P ( A ) = 4 12 = 1 3 B = { 1 , 3 , 5 , 7 , 9 , 11 } , P ( B ) = 1 2 A ∩ B = { 3 , 9 } , P ( A ∩ B ) = 1 6 P ( A / B ) = 1 / 6 1 / 2 = 1 3 = P ( A )
P(A) = P(A/B) ⇒ події A та B незалежні
⬡ Формули множення ймовірностей

Із означення умовної ймовірності — формули множення:

P ( A ∩ B ) = P ( A ) · P ( B / A ) = P ( B ) · P ( A / B )
(19) формула множення для двох залежних подій

Для n залежних подій (ланцюгове правило):

P ( ⋂ i = 1 n A i ) = P ( A 1 ) · P ( A 2 / A 1 ) · … · P ( A n / A 1 … A n − 1 )
(20) ланцюгове правило для n залежних подій

Для незалежних подій умовні дорівнюють безумовним, тому:

P ( A ∩ B ) = P ( A ) · P ( B ) , P ( ⋂ i = 1 n A i ) = ∏ i = 1 n P ( A i )
(21–22) формули множення для незалежних подій

⬡ Канонічний приклад: три екзамени (незалежні)

Імовірності здати екзамен трьома студентами: 0.9, 0.8, 0.7. Події незалежні. Знайти ймовірності трьох сценаріїв.

три сценарії на основі незалежності
⬡ Поява хоча б один раз при n незалежних спробах

Нехай в n незалежних спробах подія Ai має ймовірність pi, а qi = 1 − pi. Подія C = "Ai з'явиться принаймні один раз". Прийом: рахуємо ймовірність протилежної події (жодного разу) і віднімаємо від 1.

P ( C ) = 1 − ∏ i = 1 n q i
(23) загальний випадок різних pi
P ( C ) = 1 − q n
(24) при сталій ймовірності pi = p
⬡ Приклад: працездатність приладу

Прилад має 4 елементи з імовірностями працездатності p₁ = 0.95, p₂ = 0.9, p₃ = 0.85, p₄ = 0.8. Знайти ймовірність, що принаймні один не вийде з ладу.

Формула повної ймовірності. Формула Байєса

⬡ Гіпотези — повна група попарно несумісних подій

Нехай події B₁, B₂, …, Bn утворюють повну групу попарно несумісних:

  • Bi ∩ Bj = ∅ при i ≠ j
  • ⋃ Bi = Ω

Такі Bi називають гіпотезами: внаслідок експерименту обов'язково настає одна і тільки одна з них.

⬡ Формула повної ймовірності

Якщо подія A може відбутися лише за умови настання однієї з гіпотез Bi:

P ( A ) = ∑ i = 1 n P ( B i ) · P ( A / B i )
(25) формула повної ймовірності
де: P ( B i ) — апріорна ймовірність гіпотези до експерименту; P ( A / B i ) — умовна ймовірність A при справдженні гіпотези Bi; P ( A ) — повна (середня по всіх гіпотезах).
⬡ Канонічний приклад: 3 цехи постачають деталі

Цехи постачають у складальний 45%, 35% і 20% деталей. Браку допускають 6%, 2%, 8% відповідно. Знайти P(A) — імовірність, що навмання взята деталь стандартна.

P ( B 1 ) = 0.45 , P ( B 2 ) = 0.35 , P ( B 3 ) = 0.20 P ( A / B 1 ) = 0.94 , P ( A / B 2 ) = 0.98 , P ( A / B 3 ) = 0.92 P ( A ) = 0.45 · 0.94 + 0.35 · 0.98 + 0.20 · 0.92 = 0.95
розв'язання — формула повної ймовірності
⬡ Формула Байєса (переоцінка гіпотез)

Із формули множення для залежних подій A та Bi: P(A) · P(Bi/A) = P(Bi) · P(A/Bi). Звідси:

P ( B i / A ) = P ( B i ) · P ( A / B i ) ∑ j = 1 n P ( B j ) · P ( A / B j )
(26) формула Байєса
де: чисельник — "вклад" гіпотези Bi у настання A; знаменник — повна ймовірність A; результат — апостеріорна ймовірність Bi після того, як A відбулася.

Перевірка: Σ P(Bi/A) = 1 (апостеріорні теж утворюють повну групу).

⬡ Схема Бернуллі

Послідовність n незалежних експериментів, кожен з яких має лише два несумісні наслідки зі сталими ймовірностями. Імовірність появи події в одному експерименті — p, протилежної — q = 1 − p.

  • Простір елементарних подій одного експерименту містить 2 події
  • Простір для n експериментів — 2n подій
⬡ Формула Бернуллі

Імовірність того, що в n незалежних експериментах подія A з'явиться рівно m разів:

P n ( m ) = C n m p m q n − m = n ! m ! ( n − m ) ! p m q n − m
(1) формула Бернуллі

Імовірність появи від mi до mj разів:

P n ( m i ≤ m ≤ m j ) = ∑ m = m i m j C n m p m q n − m
(2) сума по інтервалу значень m

Сума по всіх m від 0 до n рівна 1 (умова нормування): Σ C(n,m) pᵐ qⁿ⁻ᵐ = (q + p)ⁿ = 1 — звідси й назва «біноміальний».

(5) неперервна на [a, b]

Властивості: M(C) = C; M(CX) = C · M(X); M(AX + B) = A · M(X) + B (лінійність). Якщо X ∈ [a, b], то M(X) ∈ [a, b] — центр обов'язково всередині інтервалу можливих значень.

⬡ Мода Мо та медіана Ме

Мода — значення з максимальною ймовірністю (для дискретних) або з максимальним f(x) (для неперервних). Розподіл буває одно-, дво-, багатомодальним або антимодальним.

Медіана Ме (для неперервної ВВ) — значення, що ділить ймовірнісну масу навпіл:

F ( Me ) = 0.5
(9) рівняння для медіани
∫ − ∞ Me f ( x ) d x = ∫ Me ∞ f ( x ) d x = 0.5
(10) еквівалентно через щільність

Геометрично: пряма x = Ме ділить площу під f(x) на дві рівні половини.

⬡ Дисперсія D(X) — міра розсіювання

Чому не середнє відхилення? Бо M(X − M(X)) ≡ 0. Тому беруть квадрат відхилення:

D ( X ) = M [ ( X − M ( X ) ) 2 ]
(12) означення дисперсії
D ( X ) = M ( X 2 ) − M 2 ( X )
(19) робоча формула — зручніша для обчислень
D ( X ) = ∑ i = 1 n x i 2 p i − M 2 ( X )
(20) дискретна
D ( X ) = ∫ − ∞ ∞ x 2 f ( x ) d x − M 2 ( X )
(21) неперервна

Властивості: D(X) ≥ 0 (завжди невід'ємна); D(C) = 0 (стала не розсіяна); D(CX) = C² · D(X); D(AX + B) = A² · D(X) — зсув не впливає на розсіювання.

⬡ Середнє квадратичне відхилення σ(X)

Дисперсія має розмірність "квадрату" самої величини. Зручно мати характеристику тієї ж розмірності, що й X:

σ ( X ) = D ( X )
(23) середнє квадратичне відхилення

Інтерпретація: типове відхилення X від M(X) "у звичайних одиницях". Для нормального закону ~68% значень потрапляють у [M − σ; M + σ], ~95% у [M − 2σ; M + 2σ].

⬡ Асиметрія і ексцес

Безрозмірні характеристики форми розподілу:

As = μ 3 σ 3
(31) коефіцієнт асиметрії
As = 0 — розподіл симетричний відносно M(X); As > 0 — правий хвіст довший (right-skewed); As < 0 — лівий хвіст довший (left-skewed).
Es = μ 4 σ 4 − 3
(32) ексцес
Чому "−3"? Для нормального розподілу μ₄/σ⁴ = 3, і число 3 віднімається, щоб Es нормального дорівнював 0. Es > 0 — гостровершинний (leptokurtic); Es < 0 — плосковершинний (platykurtic).
⬡ Приклад: As = 0 при симетричній f(x)

f(x) = (3/4) x(2 − x) на (0, 2]. Показати, що As = 0.

M ( X ) = ∫ 0 2 x · 3 4 x ( 2 − x ) d x = 3 4 · 16 − 12 3 = 1 μ 3 = ∫ 0 2 ( x − 1 ) 3 · 3 4 x ( 2 − x ) d x = 0
μ₃ = 0 ⇒ As = 0; розподіл симетричний відносно M(X) = 1

Ексцес Еs при цьому ≠ 0 — показує форму гостровершинності навколо центра.

Основні закони цілочислових випадкових величин

⬡ Цілочислові ВВ та твірні функції

Цілочислова ВВ — дискретна, що набуває лише цілих невід'ємних значень. Для дослідження таких ВВ використовують імовірнісну твірну функцію:

A ( x ) = ∑ k = 0 ∞ p k x k = p 0 + p 1 x + p 2 x 2 + …
(1) імовірнісна твірна функція

Властивості:

A ( 1 ) = ∑ k = 0 ∞ p k = 1
умова нормування
p k = 1 k ! A ( k ) ( 0 )
відновлення pk через k-ту похідну
M ( X ) = A ′ ( 1 )
(2) математичне сподівання
D ( X ) = A ″ ( 1 ) + A ′ ( 1 ) − ( A ′ ( 1 ) ) 2
(3) дисперсія через 2-гу похідну
⬡ Біноміальний закон

X — кількість появ події в схемі Бернуллі. Можливі значення k = 0, 1, …, n. Імовірності — за формулою Бернуллі.

p k = P ( X = k ) = C n k p k q n − k , k = 0 , 1 , … , n
(4a) ймовірності біноміального розподілу
A ( x ) = ( q + p x ) n
(4b) твірна функція
M ( X ) = n p , D ( X ) = n p q , σ ( X ) = n p q
(5–7) числові характеристики

Приклад: 400 деталей, p = 0.95 → M(X) = 380, D(X) = 19, σ(X) ≈ 4.36.

⬡ Пуассонівський закон

Граничний випадок біноміального при n → ∞, p → 0, np = a = const. Описує число рідкісних подій за фіксований час/простір.

p k = a k k ! e − a , k = 0 , 1 , 2 , …
ймовірності пуассонівського розподілу
A ( x ) = e a ( x − 1 )
твірна функція
M ( X ) = D ( X ) = a , σ ( X ) = a
унікальна властивість: M = D

Приклад: 1000 мікроелементів, p = 0.004, тоді a = 4 → M(X) = 4, D(X) = 4, σ(X) = 2.

⬡ Геометричний закон

X — число спроб до першої появи події (включно з вдалою). Спроби незалежні зі сталою p.

p k = P ( X = k ) = p q k − 1 , k = 1 , 2 , 3 , …
ймовірності геометричного розподілу
A ( x ) = p x 1 − q x , | x | < 1 / q
твірна функція
M ( X ) = 1 p , D ( X ) = q p 2 , σ ( X ) = q p
числові характеристики

Приклад: кубик до першої "6", p = 1/6, q = 5/6 → M(X) = 6, D(X) = 30, σ(X) ≈ 5.48.

Унікальна властивість: відсутність післядії — імовірність першої появи на k-му кроці не залежить від того, скільки безуспішних спроб уже було.

⬡ Рівномірний закон (дискретний)

Усі n значень k = 1, 2, …, n рівноможливі.

p k = 1 n , k = 1 , 2 , … , n
ймовірності рівномірного розподілу
M ( X ) = n + 1 2 , D ( X ) = n 2 − 1 12 , σ ( X ) = n 2 − 1 2 3
числові характеристики

Приклад: n = 100 → M(X) = 50.5, D(X) = 833.25, σ(X) ≈ 28.87.

⬡ Гіпергеометричний закон

З множини n елементів, серед яких n₁ "особливих", навмання беруть m. X = кількість "особливих" серед взятих. Без повернення (на відміну від біноміального).

p k = P ( X = k ) = C n 1 k · C n − n 1 m − k C n m , m ≤ n
ймовірності гіпергеометричного розподілу
найменше k = max(0, m − (n − n₁)); найбільше k = min(m, n₁); умова нормування Σ pk = 1.

Числові характеристики обчислюються прямо за означеннями M(X), D(X) — твірні функції тут громіздкі.
